## My Reflection

This laboratory activity taught us how to prepare a basic workspace for cloud computing tasks. We learned how to use the KillerCoda Ubuntu environment, navigate the terminal, create a user account, and gather important information about the system. We also practiced creating folders and Markdown files to keep our work organized and documented. Creating our own public GitHub repository helped us understand how technical activities can be stored and managed as a portfolio. From this activity, we realized that proper organization, documentation, and basic Linux skills are important for anyone learning cloud computing.
