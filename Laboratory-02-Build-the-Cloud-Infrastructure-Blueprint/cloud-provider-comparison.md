# Cloud Provider Comparison

## Infrastructure Service Comparison

| Infrastructure Component       | AWS        | Microsoft Azure        | Google Cloud Platform       |
| ------------------------------ | ---------- | ---------------------- | --------------------------- |
| Compute                        | Amazon EC2 | Azure Virtual Machines | Compute Engine              |
| Storage                        | Amazon S3  | Azure Blob Storage     | Cloud Storage               |
| Networking                     | Amazon VPC | Azure Virtual Network  | Virtual Private Cloud (VPC) |
| Identity and Access Management | AWS IAM    | Microsoft Entra ID     | Cloud IAM                   |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

From the three platforms, I would choose **AWS** for having the widest variety of cloud services. It provides many options covering computing, storage, networking, databases, security, and other areas. This variety can be useful when an organization has different cloud requirements.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

My choice would be **Microsoft Azure** because it fits naturally with an organization that already depends on Microsoft technologies. Using Azure can make it more convenient to connect Microsoft-based applications, accounts, and other existing resources with cloud services.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

I would select **Google Cloud Platform** for this area because of its strong presence in Artificial Intelligence and Machine Learning. Its Kubernetes services also provide support for organizations working with container-based applications.

### 4. What similarities did you observe among the three cloud providers?

The main similarity I found is that all three platforms provide the essential services needed to build cloud infrastructure. They each have computing, storage, networking, and identity or access management services. Although the service names and specific features are different, the basic functions are closely related.
