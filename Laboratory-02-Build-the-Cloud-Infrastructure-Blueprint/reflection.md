# Mission Reflection

This laboratory activity gave me a clearer idea of what happens inside a cloud infrastructure environment. By using the KillerCoda Playground, I was able to work with a Linux server and see actual information about its resources instead of only reading about them in the lesson.

I found **compute resources** particularly important because they allow the server to perform operations and handle workloads. The CPU, CPU core, and RAM work together to provide the processing capability needed by the system.

Another thing I learned was how useful Linux is in cloud computing. The terminal provides different commands for checking system information. I used commands such as `uname -r`, `nproc`, `free -h`, `df -h`, `findmnt`, `hostname`, and `hostname -I` to investigate the server.

The activity also showed me why documentation should be prepared when working with infrastructure. Recording the configuration and resources makes the information easier to review and understand. It also gives a useful reference when working with the same system later.

I improved my skills in using Linux commands, reading command outputs, organizing information, and creating Markdown documentation. I also practiced comparing cloud providers and creating an infrastructure diagram.

My GitHub portfolio became more complete after adding the different laboratory documents and outputs. Overall, the activity helped me become more familiar with Linux and gave me a better understanding of how the basic parts of cloud infrastructure work together.
