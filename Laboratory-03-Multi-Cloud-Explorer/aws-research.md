# AWS Research

## 1. Brief Overview

*Amazon Web Services (AWS)* is a cloud computing platform developed by Amazon. It delivers IT resources and services over the internet, allowing organizations to use computing power, storage, databases, networking, and other technologies without depending entirely on physical infrastructure.

AWS supports organizations of different sizes, from small startups to large enterprises. Its services can be used to develop applications, store information, operate websites, analyze data, and support business operations.

## 2. Global Infrastructure

AWS maintains a large global infrastructure made up of *AWS Regions, Availability Zones, Local Zones, and Wavelength Zones*.

An AWS Region is a geographic location where AWS provides cloud services. Within each Region are Availability Zones that are designed as separate infrastructure locations. This structure helps organizations build applications that are more reliable and resilient.

Companies can select an appropriate Region according to their geographic requirements, application performance, data regulations, and available AWS services.

## 3. Cloud Management Console

The *AWS Management Console* is an online interface that helps users manage their AWS environment. Instead of using only command-line tools, users can access and configure AWS resources through a graphical web interface.

Using the console, users can launch virtual machines, create storage resources, configure networks, manage databases, monitor resources, control permissions, and review AWS account costs.

## 4. Four Core Services

### Amazon EC2

*Amazon EC2* is a cloud computing service that provides virtual servers called instances. These instances can be configured and used for applications, websites, software systems, and other computing tasks.

### Amazon S3

*Amazon S3* provides scalable object storage. Organizations can use it to keep files, documents, media, backups, logs, and other types of digital information.

### Amazon RDS

*Amazon RDS* provides managed relational database capabilities. It helps organizations operate databases while reducing the amount of manual database administration required.

### Amazon VPC

*Amazon VPC* provides a virtual networking environment for AWS resources. It allows administrators to configure network settings such as subnets, routing, IP addresses, and security controls.

## 5. Three Advantages

1. *Flexible and scalable* – Organizations can adjust their cloud resources as their workloads increase or decrease.

2. *Reliable infrastructure* – AWS uses multiple geographic Regions and Availability Zones to help organizations design reliable and fault-tolerant applications.

3. *Comprehensive cloud services* – AWS offers a broad collection of services that can support different business and technology requirements.

## 6. Typical Enterprise Use Cases

AWS is commonly used in enterprise environments for:

* Web and application hosting
* Enterprise software deployment
* Cloud storage and backup
* Relational database management
* Development and testing environments
* Disaster recovery solutions
* Big data and analytics
* AI and machine learning applications
* Infrastructure migration
* Virtual computing and networking
