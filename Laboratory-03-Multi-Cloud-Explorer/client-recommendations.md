
# Cloud Platform Recommendations

## Client A – Startup Company

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is a practical option for the startup because it allows the company to build its infrastructure gradually. The startup does not need to purchase expensive physical servers and can instead use cloud resources according to its current requirements. As the mobile application becomes more popular, additional computing and storage resources can be added. Azure also offers managed services that can simplify infrastructure administration for a small technical team.

### Recommended Services

* *Azure App Service* – for hosting and deploying the mobile application's backend or web-based services.
* *Azure Blob Storage* – for storing images, files, and other application content.
* *Azure SQL Database* – for storing structured application information.
* *Azure Monitor* – for monitoring application performance and cloud resources.

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Azure remains the best option for the university because its existing infrastructure is already based on Microsoft technologies. Using Azure can help the university connect its current Windows Server environment and Microsoft 365 services with cloud-based resources. It can also provide centralized identity management and security controls for faculty, employees, and students.

### Recommended Services

* *Azure Virtual Machines* – for moving existing server workloads to the cloud.
* *Microsoft Entra ID* – for authentication, identity management, and access control.
* *Azure Virtual Network* – for establishing secure communication between university systems.
* *Azure Backup* – for protecting important university data and workloads.

---

## Client C – AI Research Company

### Recommended Cloud Platform: AWS

AWS is a suitable platform for the AI research company because it offers extensive computing infrastructure and specialized services for machine learning. The company can select powerful computing resources based on the requirements of its research projects. AWS also provides services that can support the complete AI development process, from storing datasets to training and deploying models.

### Recommended Services

* *Amazon SageMaker* – for building, training, and deploying machine learning models.
* *Amazon EC2* – for running customizable and high-performance computing workloads.
* *Amazon S3* – for storing large research datasets and model files.
* *Amazon EKS* – for managing containerized AI and machine learning workloads using Kubernetes.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud is an appropriate choice for the global e-commerce company because it provides global infrastructure, scalable computing, networking, and data services. The company can use Google's infrastructure to deliver applications to customers in different geographic locations. Its cloud services can also support large amounts of customer and transaction data while allowing computing resources to scale according to demand.

### Recommended Services

* *Compute Engine* – for hosting the company's web and application servers.
* *Cloud Load Balancing* – for distributing customer traffic across available servers.
* *Cloud SQL* – for managing relational e-commerce databases.
* *Cloud CDN* – for delivering website content efficiently to users in different locations.
* *Cloud Storage* – for storing product images, files, backups, and other data.

  # Multi-Cloud Decision Matrix

| Business Requirement              | Recommended Platform | Justification                                                                                                                                                                              |
| --------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Growing Startup                   | GCP                  | Google Cloud offers scalable infrastructure and managed services that can help a small company develop and expand its applications without maintaining extensive physical infrastructure.  |
| Enterprise-Level Operations       | AWS                  | AWS provides a broad selection of enterprise services, strong security capabilities, scalability, and worldwide infrastructure for complex organizational workloads.                       |
| Existing Microsoft Infrastructure | Azure                | Microsoft Azure is the natural choice for organizations already using Microsoft's ecosystem because it supports Windows Server, Microsoft 365, Entra ID, and other Microsoft technologies. |

| Kubernetes-Based Applications     | GCP                  | Google Kubernetes Engine (GKE) provides a managed Kubernetes platform that helps organizations deploy, operate, and scale containerized applications.                                      |
| Worldwide Online Service          | AWS                  | AWS can support globally distributed applications through its Regions, scalable computing services, load balancing, and content delivery capabilities.                                     |
