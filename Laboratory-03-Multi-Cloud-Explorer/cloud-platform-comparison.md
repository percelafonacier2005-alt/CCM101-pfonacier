## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?

*AWS* stands out for having one of the most extensive collections of cloud services. Its offerings cover a wide range of technologies, including virtual servers, storage, databases, networking, security, analytics, AI, and enterprise solutions. This broad portfolio gives customers more choices when building complete cloud environments.

### 2. Which provider best integrates with Microsoft technologies?

The answer is *Microsoft Azure*. Azure is designed to work with Microsoft's existing products and enterprise technologies. Organizations using Windows Server, Microsoft 365, Microsoft Entra ID, and other Microsoft services can connect these technologies with Azure, making cloud adoption easier and more centralized.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

For *AI and Kubernetes*, *Google Cloud* is a strong choice. Google provides a variety of artificial intelligence and machine learning technologies, while its *Google Kubernetes Engine (GKE)* service makes it possible to deploy and manage containerized applications using Kubernetes. These capabilities are useful for organizations working with AI and modern cloud-native systems.

### 4. Which cloud platform would you personally choose and why?

If I had to select one platform, I would choose *AWS*. My main reason is its flexibility and the large number of services available. AWS can support different types of workloads, from basic virtual machines and file storage to databases, networking, security, analytics, and AI. It would also allow me to develop a broader understanding of cloud computing by working with different cloud services on a single platform.
