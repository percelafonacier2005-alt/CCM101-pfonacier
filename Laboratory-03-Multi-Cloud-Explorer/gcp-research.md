# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP), now generally referred to as Google Cloud, is Google's collection of cloud-based computing services. It enables organizations to access IT infrastructure and software capabilities through the internet rather than maintaining all computing resources on-site.

The platform includes services for virtual computing, data storage, database management, networking, analytics, artificial intelligence, machine learning, and application development. These services allow organizations to build and operate applications on Google's infrastructure.

## 2. Global Infrastructure

Google Cloud delivers its services through a global infrastructure composed of *regions and zones*. Regions represent geographic areas, while zones provide separate deployment locations within regions.

This infrastructure allows organizations to distribute workloads according to their performance, reliability, availability, and data-location requirements. Google Cloud's network extends to *more than 200 countries and territories*, providing international connectivity for cloud-based applications.

The selection of a region or zone depends on factors such as application users, latency, compliance requirements, and service availability.

## 3. Cloud Management Console

The *Google Cloud Console* is Google's graphical management interface for cloud resources. It provides a centralized environment where administrators and developers can create, configure, monitor, and manage their cloud infrastructure.

The console can be used to deploy virtual machines, manage storage, configure virtual networks, monitor system resources, control access permissions, and work with different Google Cloud services.

## 4. Four Core Services

### Compute Engine

*Compute Engine* is an Infrastructure-as-a-Service (IaaS) offering that provides configurable virtual machines running on Google's infrastructure. It can support application hosting, development environments, enterprise workloads, and other computing requirements.

### Cloud Storage

*Cloud Storage* provides scalable object storage for data stored in Google Cloud. It can accommodate various types of information, including media, documents, backups, datasets, and application-generated files.

### Cloud SQL

*Cloud SQL* is a fully managed relational database service. It simplifies database operations by handling many administrative tasks associated with the underlying infrastructure.

### Virtual Private Cloud (VPC)

*Google Cloud VPC* provides networking functionality for cloud-based workloads. It enables organizations to design network environments and control subnets, IP addresses, routes, and communication between resources.

## 5. Three Advantages

1. *Strong analytics infrastructure* – Google Cloud offers services for processing, analyzing, and organizing large datasets, making it suitable for data-intensive workloads.

2. *Extensive global connectivity* – Google's worldwide network and cloud infrastructure allow organizations to deliver applications and services to users across different geographic locations.

3. *Integrated AI and machine learning* – Google Cloud provides infrastructure and cloud services for organizations developing, training, and deploying AI and machine learning applications.

## 6. Typical Enterprise Use Cases

Google Cloud is commonly applied in enterprise environments for:

* Web and application hosting
* Cloud-based virtual computing
* Enterprise data storage and backup
* Relational database deployment
* Data analytics and data warehousing
* Artificial intelligence and machine learning
* Software development and testing
* Container and Kubernetes workloads
* International application deployment
* Cloud migration and modernization
