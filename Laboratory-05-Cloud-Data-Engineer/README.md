# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud storage and object storage using MinIO. The mission demonstrates how to deploy an S3-compatible object storage server using Docker and store files in a cloud storage bucket.

## Objectives

- Understand the different types of cloud storage.
- Compare Block Storage, File Storage, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console.
- Create an object storage bucket.
- Upload a sample file to the bucket.
- Document the deployment and storage process.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- MinIO Web Console
- GitHub
- Web Browser

## Skills Learned

- Understanding cloud storage types and their use cases.
- Using Docker to deploy a cloud storage server.
- Managing MinIO object storage.
- Creating buckets and uploading objects.
- Accessing services through a network port.
- Documenting technical deployment steps using Markdown.
