# Mission Reflection

In this laboratory, I learned that maintaining a cloud application requires more than just starting a container. We also need to monitor the server, check application activity, and understand the information provided by monitoring tools.

Checking the host server's resources is important because containers depend on the host's CPU, memory, and disk storage. Even if a container is running, the application may become slow if the server does not have enough resources. By checking these resources regularly, we can recognize possible problems before they affect the website and its users.

If a user reports that they cannot log in to a web application, I would use docker logs to inspect the messages generated by the container. These logs may contain errors related to login requests, application failures, or connections to other services. By reviewing the available information, I can better understand what happened and decide what to investigate next.

Logs and metrics provide different types of information. Logs show individual events and requests, including errors and their details. Metrics provide numerical information about system performance, such as CPU usage, memory consumption, and network activity. Logs help explain specific events, while metrics help identify changes in performance over time.

Large companies can use monitoring platforms such as Prometheus and Grafana to manage thousands of containers. Prometheus collects performance metrics from different systems, while Grafana presents the data through dashboards and graphs. These tools allow operations teams to monitor many containers, recognize unusual resource usage, and respond to potential problems more efficiently.

My troubleshooting skills have improved because I practiced using Linux commands and Docker tools to investigate a running web application. I learned how to check available memory and storage, test website responses, read application logs, and observe container statistics. This experience taught me the importance of examining evidence before making decisions. I now have a better understanding of how monitoring helps keep applications stable and reliable.
