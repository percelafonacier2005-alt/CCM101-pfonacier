#  The Language of Automation

## 1. Bash Script

A Bash script is a file that contains commands that Linux can execute in order. The `#!/bin/bash` line is called a shebang, and it tells the system to use Bash to run the script.

## 2. Variables

Variables are used to store information, such as a folder path or a filename. For example, `$BACKUP_DIR` can store the backup folder path, so the same path does not need to be typed many times. This makes the script easier to read and update.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts automatically at a specified time. It is useful in cloud operations because it can run regular tasks, such as nightly backups, without requiring a person to start them manually.
