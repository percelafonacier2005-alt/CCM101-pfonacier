#  The Language of Automation

## 1. Bash Script

A file containing commands that Linux can run sequentially is called a Bash script. The #!The /bin/bash` line, also known as a shebang, instructs the system to execute the script using Bash.

## 2. Variables

Variables are used to store data, such as folder paths or filenames. For example, '$BACKUP_DIR' can be used to store the backup folder path, saving the user from having to type it repeatedly. This makes the script easier to understand and update.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts automatically at a specified time. It is useful in cloud operations because it can run regular tasks, such as nightly backups, without requiring a person to start them manually.
