# Mission Reflection

In this laboratory activity, I learned that automation is important when managing hundreds of cloud servers. Instead of doing the same tasks manually, we can use scripts to do the work faster and easier. Automation also helps reduce human errors and saves time. For example, my Bash script can create a backup of important files automatically.

However, automation can also be dangerous if the script has mistakes. For example, if a script contains a wrong command and runs on 1,000 servers, it could delete important files or damage many systems. This is why we must check and test our scripts before running them. We should also make sure that our scripts have the correct commands and permissions.

Writing a Bash script in Mission 9 was different from creating a Docker Compose YAML file in Mission 6. In Bash, I wrote commands that tell Linux what tasks to perform, such as creating and compressing backup files. In Docker Compose, I used YAML to describe how containers and services should work together. Both tools help automate tasks, but they have different purposes.

From Laboratory 1 to Laboratory 9, my understanding of Cloud Computing has improved. At first, I only knew a few basic concepts. As I completed the activities, I learned about cloud infrastructure, containers, networking, security, and automation. I realized that managing cloud systems requires careful planning, testing, and proper documentation.

The role I enjoyed the most was the Cloud Automation Engineer because I liked learning how to make tasks run automatically. Creating the backup script and scheduling it with Cron helped me understand how automation works in real situations. This activity also taught me to be careful when writing commands because small mistakes can cause big problems. Overall, this semester helped me gain more knowledge and confidence in Cloud Computing.
