# Final Reflection: Missions 1–10

Throughout Missions 1–10, I learned how cloud computing tools work together to create and manage an infrastructure. I explored cloud platforms, Linux, Docker, object storage, Infrastructure as Code, system monitoring, and automation. I used these lessons by setting up an Ubuntu Server virtual machine in VirtualBox and running WordPress and MariaDB through Docker Compose. I also set up UFW firewall rules to help protect the system, created a persistent Docker volume to keep database files safe, and wrote a Bash script to back up the database automatically with a cron job. I learned that creating an application is not only about making it work. It is also important to keep it secure, organized, and ready for recovery if something goes wrong. I understood why backups and persistent storage are needed to protect important data. I also practiced checking logs, reviewing firewall settings, fixing errors, and making sure all services worked properly. These activities helped me develop my problem-solving skills and become more confident in using Linux and Docker. Overall, Missions 1–10 helped me understand the tasks of managing cloud infrastructure. Through the CloudNova project, I was able to apply the lessons in one system and create clear documentation that can guide another administrator in checking, understanding, and maintaining the setup.
